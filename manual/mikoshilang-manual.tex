\begin{abstract}
MikoshiLang is a Wolfram-style symbolic language running inside Python, built on SymPy and NumPy. This edition documents current features and repaired helpers, with verified runnable examples, all 108 public Python exports, and a catalogue of 4,201 registered library names. Names, constants, aliases and algorithms are different things. MikoshiLang is alpha software: tests support checked behaviours, not correctness for every input, full Wolfram compatibility or equivalence to Mathematica.
\end{abstract}

\subsection{Session versus direct Python}
\begin{lstlisting}[language=Python]
from mikoshilang import Session
s = Session()
s.evaluate("f[x_] := x^2; f[3]")  # raw result: 9
s.eval("1/3")                    # Fraction(1, 3)
\end{lstlisting}
\texttt{Session.evaluate} returns raw values/expressions; \texttt{Session.eval} converts data to Python types. Definitions are session-local. The legacy \texttt{evaluate}/\texttt{parse\_and\_eval} interface uses a shared default session.

Imported helpers are a separate interface. Their signatures, result shapes and dispatch paths can differ from similarly named language heads. Direct \texttt{Table(fn, spec)} takes a Python callable, not a language string and iterator symbol. Tests of one interface do not automatically test the other.

\section{Language and computation}
Function calls use square brackets and lists use braces. Expressions have heads and arguments; symbols represent variables and function names. Exact integers/rationals differ from machine decimals. Unknown user heads generally remain symbolic; malformed syntax raises an error.

The core includes immediate/delayed definitions, named and typed blank patterns, sequence patterns, conditional rules, replacements, pure functions, list transformations, memoisation and specificity-ordered definitions. \texttt{Module}, \texttt{Block} and \texttt{With} implement documented scoping, including capture-avoiding substitution.

Capabilities include simplification, expansion, factorisation, differentiation, integration, limits, series and supported equation solving. \texttt{Solve} returns rule lists, not the bare roots in some old examples. \texttt{DSolve} handles supported ODEs and initial conditions, not arbitrary PDEs. \texttt{Series} includes the requested order and retains a remainder; \texttt{Normal} removes it. Convergence and solver completeness still need problem-specific checking.

\texttt{N[expr,p]} can retain arbitrary precision, but requesting more digits cannot recover information lost in machine inputs. Lists, associations, strings, number theory, statistics, matrices, graphs and numerical methods have per-head limits. Consult the catalogue and companion audit rather than assuming every name supports every form.

\section{Verification, Python integration and types}
\subsection{Independent result checks}
\texttt{Verify[expr]} distinguishes:
\begin{description}
\item[Certified] An exact certificate was checked with exact arithmetic.
\item[Checked] Symbolic or numerical evidence passed; not a general proof.
\item[Unchecked] No checker applied or the check was inconclusive.
\item[Failed] The result failed its applicable check.
\end{description}
Computation errors can still propagate. Inspect the evidence: expanding a factorisation does not establish irreducibility, and checking returned solutions does not always establish completeness. Methods include primality/product certificates, Bezout identities, substitution, differentiation, numerical comparisons and matrix residuals. This is not a trusted proof-assistant bridge.

\subsection{Python integration}
\texttt{Session.eval} converts rational data to \texttt{Fraction} and containers to lists/dictionaries. Request \texttt{symbolic="sympy"} or \texttt{arrays="numpy"} where appropriate. \texttt{Session.ns} provides Pythonic access to language heads; keyword arguments become options.

\texttt{@session.function} exposes a typed host function locally. Global \texttt{@mikoshilang.function} registration affects all sessions; \texttt{unregister} performs cleanup. \texttt{from\_python}/\texttt{to\_python} provide explicit conversion. Unsupported objects raise rather than becoming arbitrary foreign atoms.

Python imports/calls are off by default. An explicit \texttt{allow\_python} allow-list is not an operating-system sandbox. Network knowledge calls need explicit opt-in; a session flag does not sandbox direct Python calls. Untrusted evaluation needs an external process with time and memory limits. Old hosted-service and natural-language promises are not assumed available.

\texttt{PackedArray} stores supported machine numbers in NumPy-backed form. Eligible operations use NumPy paths. Unsigned values overflowing int64 are rejected rather than wrapping negative. Packed arrays are not arbitrary-precision storage.

\subsection{Opt-in type checking}
\texttt{Session(check\_types=True)} raises on concrete mismatches at checked boundaries; report mode collects mismatches. Symbolic arguments are permitted because their future values are unknown. Types cover integers with sign constraints, rationals, reals, complex numbers, variables, lists, matrices and associations. \texttt{TypeSignature}, \texttt{TypeMatchQ} and \texttt{TypeCheck} are MikoshiLang extensions. See the types guide for supported forms.

\section{Corrected helpers and scientific boundaries}
Negative direct \texttt{Take}/\texttt{Drop} counts operate on the tail. \texttt{Part[...,0]} returns the list head. Descending ranges/tables respect direction and endpoint; wrong-direction tables are empty without running their body. Zero, nonfinite and nonadvancing table steps error instead of hanging.

Complex eigenvalues/eigenvectors retain imaginary parts. Tiny determinants and matrix entries are not snapped to zero. Integer determinants use exact arithmetic before float conversion could overflow; other direct matrix operations remain numerical. GCD/LCM integer/sign/zero contracts and noninteger Fibonacci validation were repaired. Symbolic logic/comparisons preserve unknown expressions rather than Python truthiness. Calculus and symbolic Fourier helpers retain assumption-bearing SymPy variable identity while calculating; returned Mikoshi symbols do not encode those assumptions.

\texttt{Quantity}/\texttt{UnitConvert} preserve tiny values and canonical derived SI dimensions but remain floating point. Offset-temperature conversion is supported; ambiguous offset arithmetic is rejected, and temperature differences are not modelled. Element data is not a general isotope database. Neutral molecular formulas and parenthesised groups are supported; malformed formulas and unsupported charge/isotope/hydrate notation error. Chemical balancing uses exact rational arithmetic for unique strictly positive balances, not rounded guesses.

Direct DFT/IDFT use NumPy's negative forward exponent and $1/n$ inverse normalisation; direct symbolic Fourier transforms use SymPy's convention. Do not blindly compare these with the session's Wolfram-style Fourier convention. Complex signal components are preserved. Numerical signal helpers require finite nonempty one-dimensional lists; cutoffs are finite, ordered and strictly below Nyquist. Tests do not guarantee high-order filter stability. SciPy is optional; spectrogram plotting needs matplotlib, otherwise the documented raw frequency/time/power form is returned.

\section{Test evidence and honest limits}
At the PR 89 audit snapshot, 436 new audit cases plus 118 earlier regressions gave 554 passing focused cases locally, both from source and installed wheels. A minimal environment gave 484 passed and 70 optional skips. Full-suite comparison on Windows/Python 3.14 gave 30,229 passed, 78 pre-existing failures and 9 skips, with zero new failing identities and no tests removed. These are dated results, not guarantees for future revisions.

Pre-merge CI passed the executed source/wheel and minimal jobs on Ubuntu and Windows with Python 3.9, 3.12 and 3.13; optional full-verification jobs were skipped. No licensed Wolfram kernel was used as an oracle. Shared-backend comparisons supplement independent known values, identities and residuals. This public-surface audit is not an exhaustive audit of every registered head or class method.

\section{Rebuilding and contributing}
Follow \texttt{manual/REBUILD.md}. Regenerate the live function reference and execute the example checker before compiling the PDF. Do not edit generated files by hand. Keep source and PDF together so the document can be reproduced.

Contributions should test the actual public entry point and state unsupported inputs. For a bug, demonstrate a failing regression before the narrow repair. A name count is not a correctness score, and a passing example does not justify removing an honest limitation.
